적용 방법

xdelta 형식 공통
  1. 패처 준비 — Delta Patcher(GUI) 또는 xdelta3(CLI)
  2. 원본 확인 — 각 게임 설명서에 적힌 원본 해시(MD5) 와 내 파일이 같은지 대조
  3. 패치 적용 
    xdelta3 -d -s <원본> <패치.xdelta> <출력>
게임별 형식이 다르면 해당 게임 설명서의 적용법을 따르세요.
