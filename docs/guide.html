01 — BASICS

시작하기 · 기본 개념Getting Started

이 프로그램은 콘솔 에뮬레이터용 ROM 파일에 메타데이터(제목·설명·이미지·영상·매뉴얼)를 자동으로 붙여, ES-DE·EmulationStation 같은 프론트엔드용 gamelist.xml을 만들고, 그 결과를 PC·안드로이드·리눅스 휴대용 기기로 내보내는 도구입니다. This tool automatically attaches metadata (title, description, images, video, manuals) to console-emulator ROM files, builds a gamelist.xml for front-ends like ES-DE / EmulationStation, and exports the result to PC, Android, or Linux handhelds.

화면 구성Screen layout

화면은 크게 왼쪽의 시스템 목록과 오른쪽의 게임 목록/정보로 나뉩니다. 시스템을 고르면 그 시스템의 게임들이 오른쪽에 뜨고, 게임을 고르면 정보·미디어·영상·매뉴얼을 볼 수 있습니다. 상단 우측에는 테마·언어(한/영, 재시작 없이 즉시 전환)·설정·후원 ♥ 버튼이 있습니다. The screen is split into the system list (left) and the game list / details (right). Pick a system to list its games; pick a game to see its info, media, video and manual. The top-right holds theme, language (KO/EN, switches instantly without a restart), settings, and Donate ♥.

기본 흐름 — ① 시스템 추가 → ② ROM 자동 매칭·미디어 다운로드 → ③ 필요하면 메타/미디어 편집 → ④ 기기로 내보내기. 이미 다른 프론트엔드로 세팅해 둔 라이브러리가 있다면 ①을 가져오기로 대체할 수 있습니다. Typical flow — ① add a system → ② auto-match ROMs & download media → ③ tweak metadata/media if needed → ④ export to your device. If you already have a library set up in another front-end, you can replace ① with Import.
데모 버전을 쓰고 계신다면 — 체험용 제약이 있습니다. 메가드라이브·슈퍼패미컴 2개 시스템, 시스템 최대 2개, 게임 최대 100개까지 추가할 수 있고 그 외 기능은 모두 동일합니다. 제약이 풀린 1.0 베타는 새로운 소식에서 안내합니다. Using the demo build? — it has trial limits: only Mega Drive & Super Famicom, up to 2 systems and 100 games. Everything else works the same. See News for the unrestricted 1.0 beta.

02 — SYSTEMS

시스템 관리Managing Systems

시스템 추가Add a system

왼쪽 목록의 시스템 추가를 눌러 시작합니다. 추가할 콘솔 종류(예: 메가드라이브, 슈퍼패미컴, PSX…)를 고르고, 그 콘솔의 ROM 폴더를 지정하면 됩니다. Click Add System on the left panel. Choose the console type (e.g. Mega Drive, Super Famicom, PSX…) and point it at that console's ROM folder.

  1. 콘솔 종류 선택 — 지원 시스템 목록에서 선택합니다. 시스템별로 인식하는 ROM 확장자가 정해져 있습니다.Pick the console from the supported list. Each system knows which ROM extensions to recognize.
  2. ROM 폴더 지정 — 폴더를 고르면 하위의 ROM을 스캔합니다. (폴더 없이 빈 시스템으로 먼저 추가한 뒤 나중에 ROM을 넣어도 됩니다.)Choose the ROM folder — its ROMs are scanned. (You can also add an empty system first and add ROMs later.)
  3. 자동 매칭 + 미디어 다운로드 — 파일명을 분석해 게임을 찾아 제목·장르·이미지·영상 등을 자동으로 채웁니다. 진행률은 0~20% 매칭, 20~95% 미디어 다운로드로 표시됩니다.Auto-match + media download — filenames are analyzed to identify each game and fill in title, genre, images, video, etc. Progress shows 0–20% matching, 20–95% media download.

추가 후 시스템 행에서 설명(표시 이름)과 메타 폴더명을 편집할 수 있습니다. 폴더명은 내보낼 때 사용되는 시스템 폴더 이름입니다(비워 두면 표준 이름 사용). After adding, you can edit the system's display name and meta folder name on its row. The folder name is used as the system's folder when exporting (leave blank to use the standard name).

매칭 정확도 — 고유 알고리즘으로 한글 파일명을 포함해 수십 초 안에 수백 개 ROM을 매칭합니다. 매칭이 애매한 게임은 매칭 방식 열 색상으로 구분되며, 아래 메타 편집기에서 직접 바로잡을 수 있습니다. Accuracy — a proprietary algorithm matches hundreds of ROMs in seconds, including Korean-named files. Uncertain matches are color-coded in the Matching column and can be fixed in the Meta Editor below.

재스캔Re-scan

ROM 폴더가 바뀌었거나 매칭을 다시 돌리고 싶을 때 사용합니다. 세 가지 옵션이 있습니다.Use when the ROM folder changed or you want to re-run matching. Three options:

옵션Option동작Behavior
전체 재스캔Total re-scan모든 게임을 다시 매칭합니다. 직접 수정했던 메타가 자동 매칭으로 초기화되며, 사라진 ROM은 목록에서 제거됩니다.Re-matches every game. Manually edited metadata is reset to auto-match; missing ROMs are removed from the list.
재스캔 (수정한 게임 제외)Re-scan (keep edits)직접 수정한 게임은 건드리지 않고, 나머지만 다시 매칭합니다. 사라진 ROM은 제거됩니다.Leaves your edited games untouched and re-matches the rest. Missing ROMs are removed.
삭제된 롬만 제거Prune deleted only매칭은 하지 않고, 폴더에서 사라진 ROM만 목록에서 정리합니다.No matching — just removes list entries whose ROM files are gone.

게임 하나만 다시 매칭하려면 그 게임에서 이 게임만 재스캔을, 여러 개는 체크 후 선택 게임 재스캔을 사용합니다.To re-match a single game use Re-scan only this game; for several, check them and use Re-scan checked.

04 — META EDITOR

메타 편집기Meta Editor

게임을 우클릭하거나 게임 메타 편집을 눌러 엽니다. 잘못 매칭됐거나 비어 있는 정보를 바로잡고, 원하는 이미지·영상·매뉴얼로 교체하는 곳입니다.Right-click a game or press Edit Meta. This is where you fix wrong/missing matches and swap in the images, video and manual you want.

후보 찾기 — 추천 · 검색 · 실시간 조회Finding the right game

  • 추천 리스트 — 현재 파일명에 가장 가까운 후보들을 자동으로 보여줍니다.Recommend list — auto-suggests the closest candidates for the current filename.
  • 전체 검색 — 제목을 직접 입력해 마스터 DB에서 찾습니다.Search — type a title to search the master database directly.
  • ScreenScraper 실시간 조회 — 로컬 DB에 없는 게임을 온라인(ScreenScraper)에서 즉시 검색해 적용합니다(계정 설정 필요).Live ScreenScraper lookup — for games not in the local DB, search online (ScreenScraper) and apply instantly (needs a configured account).
  • AI로 채우기 — 텍스트 정보가 부족할 때 LLM으로 제목·설명 등을 보완합니다(AI 설정 필요).AI fill — when text info is sparse, use an LLM to complete title/description (needs AI settings).

후보를 고르면 미리보기(믹스 이미지)가 뜨고, 원하는 리전을 선택할 수 있습니다.Choosing a candidate shows a preview (mix image) and lets you pick the desired region.

텍스트 편집Text fields

직접 고칠 수 있는 항목: 제목(영문), 제목(한글), 게임 설명, 장르, 출시일, 개발사, 플레이어 수.Editable fields: Title (EN), Title (KR), Description, Genre, Release date, Developer, Players.

미디어 편집Media editing

각 미디어 슬롯(타이틀·스크린샷·휠·커버·케이스·3D박스·서포트·영상·매뉴얼)마다 다음을 할 수 있습니다.For each media slot (title, screenshot, wheel, cover, box texture, 3D box, support, video, manual) you can:

  • 불러오기 — 내 PC 이미지 파일로 교체.Load — replace with an image file from your PC.
  • 웹 이미지 검색 / URL — 인터넷에서 이미지를 찾아 가져오기. 구글 이미지 열기도 지원.Web image search / URL — fetch an image from the web; open Google Images too.
  • 편집 — 자르기, 배경 투명화, 정면화(서포트/케이스), 로고 투명 처리.Edit — crop, make background transparent, flatten (support/case), transparent-logo processing.
  • 3D 박스 생성 — 앞표지 이미지로 3D 박스 아트를 만듭니다.Generate 3D box — build 3D box art from the cover image.
  • 영상 가져오기 · 자르기 — YouTube 검색/URL로 영상을 받아 원하는 구간만 트림.Fetch / trim video — grab a clip via YouTube search/URL and trim to the segment you want.
원본에 반영 & 리전 — 새로 만든/교체한 미디어는 리전을 지정해 저장합니다. 파일은 {게임ID}_{종류}_{리전} 규칙으로 정규화됩니다. 원본 반영 옵션을 켜면 현재 목록뿐 아니라 원본 미디어 소스에도 업로드됩니다(작성자 전용).Region & source — new/replaced media is saved with a chosen region. Files are canonicalized as {gameID}_{type}_{region}. Enabling Update source uploads to the original media source, not just your local list (author-only).

미매칭 전환 — 잘못 매칭된 게임을 "매칭 안 됨" 상태로 되돌립니다. 적용을 누르면 편집 내용이 저장되고 목록·믹스 이미지가 갱신됩니다.Convert to unmatched — resets a wrongly matched game to "unmatched." Press Apply to save edits and refresh the list & mix image.

한 번 레이아웃을 정하면 이후 추가되는 게임의 믹스 이미지에도 자동으로 같은 스타일이 적용됩니다.Once set, the same style automatically applies to the mix images of games you add later.

07 — SETTINGS

전역 설정Global Settings

리전 우선순위Region priority

한 게임에 여러 지역판 미디어(일본/북미/유럽/한국 등)가 있을 때, 어느 지역을 우선으로 받고 표시할지 순서를 정합니다. 시스템별로 다른 순서를 저장할 수도 있습니다.When a game has media for multiple regions (JP/US/EU/KR…), set the preferred order for downloading and display. You can save a different order per system.

AI 설정AI settings

  • 제공자 / 모델 / API 키 — ChatGPT 또는 Gemini 등을 선택하고 키를 입력합니다. 검증 버튼으로 키가 유효한지 확인할 수 있습니다.Provider / model / API key — pick ChatGPT or Gemini, enter your key, and use Validate to confirm it works.
  • 이미지 번역 옵션 — 매뉴얼 페이지의 이미지 위 텍스트를 번역해 덮어씌우는 기능에 사용됩니다.Image-translation option — used to translate and overlay text on manual page images.

ScreenScraper 계정ScreenScraper account

로컬 DB에 없는 게임을 온라인에서 실시간 조회하려면 개인 ScreenScraper 계정(아이디/비밀번호)을 설정에 입력합니다. 개인 계정을 쓰면 개인 할당량으로 더 안정적으로 조회됩니다.To look up games not in the local DB online in real time, enter your personal ScreenScraper account (user/password) in Settings. Using your own account gives you a personal quota for more reliable lookups.

언어 · 테마 — 설정에서 한/영과 라이트/다크 테마를 재시작 없이 즉시 바꿀 수 있습니다.Language · theme — switch KO/EN and light/dark theme instantly, no restart, from Settings.

08 — EXPORT

내보내기Export

완성한 게임 목록과 미디어를 gamelist.xml과 함께 기기로 내보냅니다. 한 개 이상의 시스템을 골라 시작합니다.Send your finished game list and media — together with gamelist.xml — to a device. Pick one or more systems to begin.

먼저 어디로 보낼지(연결 방식)를 고르고, 그 다음 어떤 프론트엔드 규약으로 만들지를 고릅니다. 이 두 가지는 별개입니다.First choose where to send it (the connection), then which front-end layout to build. These are two separate choices.

3) 폴더 이름과 롬 경로3) Folder names & ROM paths

  • 롬 경로 (기기) — 기기에서 게임이 들어갈 최상위 경로입니다. 연결하면 자동으로 채워지고, 📂 탐색으로 기기 안을 직접 둘러보며 고를 수도 있습니다.ROMs path (device) — the root where games go on the device. It's auto-filled on connect, and 📂 Browse lets you pick it by exploring the device.
  • 내보내기 폴더 — 시스템마다 폴더 이름을 지정할 수 있습니다. 고른 프론트엔드의 공식 시스템명으로 자동 보정되며(예: ES-DE에서 Atari Lynx는 atarilynx), 직접 고쳐도 됩니다. 바꾸면 즉시 저장됩니다.Export folder — a folder name per system. It's auto-corrected to the chosen front-end's official system name (e.g. Atari Lynx becomes atarilynx on ES-DE) and is editable. Edits save immediately.
  • 하위 폴더 — / 로 구분해 snes/hack 처럼 적으면 그 하위에 들어갑니다. 여러 시스템을 같은 폴더로 지정하면 하나로 합쳐 내보냅니다.Subfolders — write snes/hack with a / to nest it. Point several systems at the same folder and they are merged on export.
  • 롬 경로 (시스템별) — ES-DE 전용입니다. ES-DE는 custom_systems 로 시스템마다 롬 위치를 다르게 둘 수 있어서, 그 구성에 맞춰 이 시스템만 다른 절대경로로 보낼 수 있습니다. 비우면 Default(위의 롬 경로 기준)입니다.Per-system ROM path — ES-DE only. ES-DE can point each system at a different location via custom_systems, so you can send just that system elsewhere. Leave it empty for Default (relative to the ROMs path above).
시스템별 롬 경로는 ES-DE에서만 보입니다 — 다른 프론트엔드는 gamelist.xml과 미디어가 롬 폴더 안에 있어야 하고 고정된 롬 루트만 훑기 때문에, 롬만 딴 곳으로 옮기면 게임이 전부 인식되지 않습니다.Per-system ROM paths appear only for ES-DE — other front-ends need gamelist.xml and media inside the ROM folder and only scan a fixed ROM root, so moving just the ROMs would break every game.

4) 게임 목록 처리 · 전송4) Game list handling & transfer

  • 게임 목록(gamelist) 처리 — 병합 (권장)은 기기에 이미 있는 목록을 지우지 않고 선택한 게임만 갱신·추가합니다. 즐겨찾기·플레이 횟수처럼 기기에서 관리되는 값도 보존됩니다. 전체 교체는 목록을 통째로 새로 씁니다.Game list handling — Merge (recommended) keeps the device's existing list and only updates/adds the selected games, preserving device-managed values like favorites and play counts. Replace rewrites the whole list.
  • ROM 파일도 복사 — 메타뿐 아니라 ROM 자체를 함께 보냅니다. 이름·크기가 같은 파일은 건너뛰므로, 두 번째 내보내기부터는 훨씬 빠릅니다.Copy ROM files too — sends the ROMs as well as the metadata. Files with the same name and size are skipped, so repeat exports are much faster.
  • 컨트롤러 키 설정 포함 — 6장에서 만든 시스템·게임별 입력 설정을 함께 내보냅니다. RetroArch가 없는 기기에서는 무시됩니다. 리맵 경로는 자동으로 잡히고, 필요하면 직접 지정할 수 있습니다.Include controller mappings — exports the per-system/per-game input configs from chapter 6. Ignored on devices without RetroArch. The remap path is detected automatically, or you can set it yourself.
  • PS Vita — .vpk 를 풀어 기기의 Vita3K 앱 폴더로 바로 설치합니다. 이미 설치된 타이틀은 건너뛰고, 기기에 Vita3K가 없으면 수 GB를 헛되게 보내지 않고 미리 알려 줍니다.PS Vita — .vpk files are unpacked straight into the device's Vita3K app folder. Already-installed titles are skipped, and if Vita3K is missing you're told up front instead of wasting a multi-GB transfer.

전송이 시작되면 단계별 진행률이 표시됩니다. 큰 ROM 파일은 게임파일명 (234MB / 764MB) [3/91] 처럼 바이트 단위로 진행 상황이 보이고, 취소도 가능합니다.Once transfer starts you get per-phase progress. Large ROMs report byte-level progress like game.zip (234MB / 764MB) [3/91], and you can cancel at any time.

OS마다 폴더·파일 규칙이 다른데, 프로그램이 고른 프론트엔드에 맞춰 경로와 이름을 자동으로 맞춰 줍니다. 전송하지 못한 파일이 있으면 몇 개가 실패했는지 파일명과 함께 알려 주고, 다시 내보내면 실패한 파일만 재전송합니다.Folder and file conventions differ per OS; the tool adapts paths and names to the chosen front-end. If any file fails to transfer you're told how many failed, with their names — and re-exporting retries only those.
안드로이드 연결이 안 될 때 — 케이블 연결 상태에서 USB 디버깅을 껐다가 다시 켜 보세요. 기기에 뜨는 USB 디버깅 허용 창도 확인해야 합니다.If Android won't connect — with the cable plugged in, toggle USB Debugging off and on. Also accept the Allow USB debugging prompt on the device.

09 — IMPORT

가져오기Import

내보내기의 반대 방향입니다. 이미 다른 프론트엔드로 세팅해 둔 라이브러리를 이 프로그램으로 읽어들여 시스템과 게임을 한 번에 등록합니다. ROM 폴더를 처음부터 다시 스캔할 필요가 없습니다.The reverse of Export. Read a library you already set up in another front-end and register its systems and games in one pass — no need to re-scan your ROM folders from scratch.

지원하는 원본은 ES-DE(gamelist.xml)와 Pegasus(metadata.pegasus.txt)이며, 읽어올 위치는 내 컴퓨터 · 안드로이드 · 커스텀 리눅스(SFTP) 세 곳입니다.Supported sources are ES-DE (gamelist.xml) and Pegasus (metadata.pegasus.txt), read from this PC, Android, or custom Linux (SFTP).

내 컴퓨터에서 가져오기From this PC

  • ES-DE — ES-DE/gamelists 폴더를 고릅니다. ES-DE 루트를 골라도 알아서 찾습니다. 미디어는 downloaded_media 규약을 따라 자동으로 연결됩니다.ES-DE — pick the ES-DE/gamelists folder (picking the ES-DE root works too). Media is matched automatically via the downloaded_media convention.
  • Pegasus — 시스템 폴더들의 상위 폴더를 고르거나, 자동 감지로 설정 폴더(%LOCALAPPDATA%\pegasus-frontend)를 찾게 합니다. 설정 폴더를 고르면 game_dirs.txt에 등록된 게임 폴더들을 따라갑니다.Pegasus — pick the parent folder of your system folders, or hit Auto to locate the config folder (%LOCALAPPDATA%\pegasus-frontend). From there it follows the game folders listed in game_dirs.txt.
  • 롬 루트 폴더 — 자동으로 추정하지만 맞지 않으면 직접 고칠 수 있습니다.ROM root folder — auto-guessed, and editable if the guess is off.

기기에서 가져오기From a device

기기의 라이브러리를 지정한 로컬 폴더로 복제한 뒤, 그 파일을 기준으로 등록합니다. 원본 기기는 읽기만 합니다.The device library is copied into a local folder you choose, then imported from those files. The device itself is only read.

  1. 복제 대상 폴더를 지정합니다. 롬과 미디어가 이 폴더에 저장됩니다.Choose the destination folder — ROMs and media are copied here.
  2. 기기 검색을 누르면 메타파일만 먼저 빠르게 받아 시스템 목록을 보여줍니다. 게임 수도 함께 표시됩니다.Hit Scan device — only the metadata files are fetched first, giving you the system list with game counts.
  3. 가져올 시스템을 체크하고 표시이름 접두를 정한 뒤(예: [Android]) 실행합니다. 선택한 시스템의 롬·미디어만 내려받습니다.Check the systems you want, set a display-name prefix (e.g. [Android]) and run. Only the selected systems' ROMs and media are pulled.
가져올 위치Source device지원 원본 · 준비물Supported sources · requirements
안드로이드AndroidES-DE 와 Pegasus 모두 가져올 수 있습니다. USB 연결 + 파일전송(MTP)·USB 디버깅 허용 상태여야 합니다.Both ES-DE and Pegasus. Requires USB connection with file transfer (MTP) and USB debugging allowed.
커스텀 리눅스(SFTP)Custom Linux (SFTP)EmulationStation 계열 구조(<시스템>/gamelist.xml)를 읽습니다. IP·계정·비밀번호와 원격 롬 경로가 필요합니다.Reads the EmulationStation-family layout (<system>/gamelist.xml). Needs IP, account, password and the remote ROM path.
가져온 게임은 모두 수동(manual) 상태로 등록되고, 미디어는 캐시로 복사됩니다. 가능한 경우 마스터 DB의 게임과 자동으로 연결해 두므로, 이후 메타 편집기에서 더 나은 후보로 교체할 수 있습니다.Imported games are registered as manual and their media is copied into the cache. 가져온 시스템을 전체 재스캔하면 주의 — 수동으로 들어온 데이터가 초기화됩니다. 목록에서 미지원으로 표시된 시스템은 이 앱의 메타 서버·자동매칭 대상이 아니라 로컬 전용으로 추가됩니다.Careful with a full re-scan of an imported system — it resets the manually imported data. Systems shown as unsupported are added local-only, outside this app's metadata server and auto-matching.

10 — DEVICE BROWSER

기기 탐색기 · 파일 편집Device Browser & File Editing

안드로이드(ADB) 또는 SFTP로 연결한 뒤 📂 탐색을 누르면 기기 내부를 직접 둘러볼 수 있습니다. 내보내기 화면에서 롬 경로를 눈으로 확인하고 지정할 때 가장 요긴합니다.Connect over Android (ADB) or SFTP, then hit 📂 Browse to explore the device. It's most useful for seeing and picking the ROM path during export.

  • 폴더 작업 — 새 폴더 만들기, 복사·잘라내기·붙여넣기, 삭제, 여러 항목 선택.Folder operations — new folder, copy / cut / paste, delete, multi-select.
  • 이 폴더로 지정 — 현재 보고 있는 폴더를 롬 경로로 바로 설정합니다. 시스템별 롬 경로도 각 행의 작은 📁 버튼으로 이렇게 지정할 수 있습니다.Use this folder — sets the folder you're viewing as the ROM path. Per-system ROM paths can be picked the same way via the small 📁 button on each row.
