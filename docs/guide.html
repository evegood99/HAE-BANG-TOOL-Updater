01 — BASICS

시작하기 · 기본 개념Getting Started

이 프로그램은 콘솔 에뮬레이터용 ROM 파일에 메타데이터(제목·설명·이미지·영상·매뉴얼)를 자동으로 붙여, ES-DE·EmulationStation 같은 프론트엔드용 gamelist.xml을 만들고, 그 결과를 PC·안드로이드·리눅스 휴대용 기기로 내보내는 도구입니다. This tool automatically attaches metadata (title, description, images, video, manuals) to console-emulator ROM files, builds a gamelist.xml for front-ends like ES-DE / EmulationStation, and exports the result to PC, Android, or Linux handhelds.

화면 구성Screen layout

화면은 왼쪽의 시스템 목록, 가운데의 게임 목록, 오른쪽의 게임 정보 패널로 나뉩니다. 시스템을 고르면 그 시스템의 게임들이 가운데에 뜨고, 게임을 고르면 오른쪽에 정보·미디어·영상·매뉴얼이 펼쳐집니다(그동안 시스템 목록은 좁게 접힙니다). 상단 바 우측에는 Tools(도구 — APK 보관함)·⚙ 설정(언어·테마·AI·ScreenScraper)·♥ 후원 버튼이 있고, 앱 이름 옆에 현재 버전과 BETA / PLUS+ 배지가 표시됩니다. The screen is split into the system list (left), the game list (center) and the game info panel (right). Pick a system to list its games; pick a game and its info, media, video and manual open on the right (the system list folds narrow meanwhile). The top bar holds Tools (APK library), ⚙ Settings (language, theme, AI, ScreenScraper) and ♥ Donate, with the current version and BETA / PLUS+ badges next to the app name.

시스템 목록 위의 도구줄에는 + 시스템, ⬆ 내보내기, ⬆ HB런처(초록 버튼) 와 아이콘 버튼 — ↻ 선택 재스캔, 프론트엔드 설정(코어/실행기), 🎮 컨트롤러 키설정, 🌐 전역 리전 우선순위, 🗑 선택 삭제 — 가 있습니다. 게임 목록 위에는 + 폴더·+ 파일·복사·이동·삭제·검색이 있고, 디스크를 여러 장 고르면 M3U 병합 버튼이 나타납니다. The toolbar above the system list has + System, ⬆ Export, ⬆ HB Launcher (green) and icon buttons — ↻ rescan selected, front-end settings (cores/launch), 🎮 controller mapping, 🌐 global region priority, 🗑 delete selected. Above the game list are + Folder, + Files, Copy, Move, Delete and search; select several discs and a Merge M3U button appears.

기본 흐름 — ① 시스템 추가 → ② ROM 자동 매칭·미디어 다운로드 → ③ 필요하면 메타/미디어 편집 → ④ 기기로 내보내기(ES-DE 등 프론트엔드) 또는 HB런처로 보내기. 이미 다른 프론트엔드로 세팅해 둔 라이브러리가 있다면 ①을 가져오기로 대체할 수 있습니다. Typical flow — ① add a system → ② auto-match ROMs & download media → ③ tweak metadata/media if needed → ④ export to your device (ES-DE and other front-ends) or send to HB Launcher. If you already have a library set up in another front-end, you can replace ① with Import.
공개 버전(v1.0)을 쓰고 계신다면 — 일부 시스템(닌텐도 스위치 등)이 빠져 있고, 다음 개선은 메이저 업데이트(1.1 · 1.2 …) 때 한꺼번에 반영됩니다. 후원자 베타는 마이너 업데이트를 계속 받고 시스템 제외도 없습니다 — 다운로드에서 두 갈래를 비교해 보세요. On the public build (v1.0)? — some systems are left out (Nintendo Switch and others), and further improvements land together at the next major version (1.1, 1.2 …). The sponsor beta keeps receiving minor updates with no systems excluded — compare the two on the download page.

02 — SYSTEMS

시스템 관리Managing Systems

시스템 추가Add a system

왼쪽 목록의 + 시스템을 누르면 먼저 추가 방식을 묻습니다 — 로컬 (롬 파일)은 내 PC의 롬 폴더를 스캔해 자동 매칭하고, 외부 세팅 정보 (가져오기)는 ES-DE·Pegasus 라이브러리나 안드로이드·SFTP 기기의 목록을 그대로 들여옵니다(10장). 로컬을 고르면 콘솔 종류(예: 메가드라이브, 슈퍼패미컴, PSX…)와 그 콘솔의 ROM 폴더를 지정합니다. Press + System on the left panel and choose how to add — Local (ROM files) scans a ROM folder on this PC and auto-matches it, while External library (Import) pulls in an existing ES-DE / Pegasus library or a list from an Android / SFTP device (chapter 10). For Local, pick the console type (e.g. Mega Drive, Super Famicom, PSX…) and that console's ROM folder.

  1. 콘솔 종류 선택 — 지원 시스템 목록에서 선택합니다. 시스템별로 인식하는 ROM 확장자가 정해져 있습니다.Pick the console from the supported list. Each system knows which ROM extensions to recognize.
  2. ROM 폴더 지정 — 폴더를 고르면 하위의 ROM을 스캔합니다. (폴더 없이 빈 시스템으로 먼저 추가한 뒤 나중에 ROM을 넣어도 됩니다.)Choose the ROM folder — its ROMs are scanned. (You can also add an empty system first and add ROMs later.)
  3. 표시 이름 · 리전 접미사 — 목록에 보일 이름을 정하고, 원하면 파일명 리전 태그를 제목 접미사로 표시를 켭니다 — (Korea)는 (정발판), (Japan)은 (일본판)처럼 제목 뒤에 붙습니다. 기본은 꺼짐입니다.Display name · region suffix — set the name shown in the list and, if you like, turn on append filename region tag to title — (Korea) and (Japan) tags become a suffix on the title. Off by default.
  4. 자동 매칭 + 미디어 다운로드 — 파일명을 분석해 게임을 찾아 제목·장르·이미지·영상 등을 자동으로 채웁니다. 진행률은 0~20% 매칭, 20~95% 미디어 다운로드로 표시됩니다.Auto-match + media download — filenames are analyzed to identify each game and fill in title, genre, images, video, etc. Progress shows 0–20% matching, 20–95% media download.

추가 후 시스템 행에서 설명(표시 이름)과 메타 폴더명을 편집할 수 있습니다. 폴더명은 내보낼 때 사용되는 시스템 폴더 이름입니다(비워 두면 표준 이름 사용). After adding, you can edit the system's display name and meta folder name on its row. The folder name is used as the system's folder when exporting (leave blank to use the standard name).

매칭 정확도 — 고유 알고리즘으로 한글 파일명을 포함해 수십 초 안에 수백 개 ROM을 매칭합니다. 매칭이 애매한 게임은 매칭 방식 열 색상으로 구분되며, 아래 메타 편집기에서 직접 바로잡을 수 있습니다. 설정의 AI 사용을 켜 두면 파일명만으로 확정이 안 되는 게임은 후보를 추려 LLM에게 최종 판정을 맡깁니다. Accuracy — a proprietary algorithm matches hundreds of ROMs in seconds, including Korean-named files. Uncertain matches are color-coded in the Matching column and can be fixed in the Meta Editor below. With AI enabled in Settings, games the filename alone can't settle are handed to the LLM with a shortlist of candidates.

게임 추가 · 복사 · 이동 · 우클릭 메뉴Adding, copying, moving & the right-click menu

이미 만든 시스템에 게임을 더하거나 옮길 때 쓰는 기능입니다. 게임 목록 위의 버튼과, 게임을 우클릭했을 때 뜨는 메뉴 두 곳에서 쓸 수 있습니다.Once a system exists, these add or move games within it — from the buttons above the game list, or from the right-click menu on a game.

기능Feature설명What it does
+ 폴더+ Folder폴더를 골라 그 안의 ROM을 스캔해 현재 시스템에 추가합니다. 이미 있는 파일은 건너뜁니다.Pick a folder; its ROMs are scanned and added to the current system. Existing files are skipped.
+ 파일+ Files개별 ROM 파일을 골라(또는 드래그드롭) 추가합니다.Select individual ROM files (or drag-and-drop) to add.
복사 / 이동Copy / Move체크한 게임을 같은 종류의 다른 시스템으로 복사하거나 이동합니다. 같은 콘솔이라 미디어·캐시가 그대로 호환됩니다. 여러 개를 체크한 채 우클릭하면 그 전부에 걸립니다.Copy or move checked games to another system of the same type. Media and cache stay compatible since the console is identical. Right-clicking with several checked applies to all of them.

우클릭 메뉴에는 메뉴 위쪽에 지금 고른 게임 이름·파일명이 보이고, 메타 편집 · 패치 적용…(아래) · 탐색기에서 보기 · 다른 시스템으로 복사/이동 · 삭제가 모여 있습니다. 게임 목록에서는 체크박스 다중 선택과 검색도 됩니다. The right-click menu names the selected game and file at the top and gathers Edit metadata, Patch ROM… (below), Show in Explorer, Copy / Move to another system and Delete. The game list also supports multi-select checkboxes and search.

ROM 패치 적용 · M3U 병합Patch ROM · Merge M3U

게임을 우클릭해 패치 적용…을 누르면 그 ROM의 CRC32 · MD5 해시가 보이고, 항목마다 패치 파일을 지정해 바로 입힐 수 있습니다. 내 롬이 No-Intro 같은 대조표의 어느 판본인지 확인하고, 대한글화시대에서 받은 한글화 패치를 툴 안에서 바로 적용하는 자리입니다.Right-click a game and choose Patch ROM… to see its CRC32 · MD5 hashes and apply a patch file per entry. Use it to check which No-Intro dump you have and to apply Korean translation patches from the KR Patches page without leaving the tool.

  • 지원 형식 — IPS · IPS32 · BPS · UPS · PPF · APS · Xdelta, 드림캐스트 GD-ROM은 DCP(디스크 전체에 적용)까지.Formats — IPS, IPS32, BPS, UPS, PPF, APS and Xdelta, plus DCP for Dreamcast GD-ROMs (applies to the whole disc).
  • 압축 파일은 그릇일 뿐이라 통째로 패치하지 않고 압축 안의 롬에 겁니다 — 한글화 패치는 대개 압축을 푼 롬 기준이기 때문입니다. 안쪽 항목의 해시도 함께 보여 줍니다. 7z는 기본 설정으로 다시 묶이고, CHD는 풀고 → 적용하고 → 다시 묶습니다(몇 분 소요).Archives are only containers, so the patch goes on the ROM inside — translation patches are normally built against the unzipped ROM. Hashes of the inner entries are shown too. 7z files are repacked with default settings; a CHD is extracted → patched → repacked (takes a few minutes).
  • 폴더형 게임(PS1의 cue/bin 등)은 폴더째 새로 만들어 그 안의 파일을 바꿉니다.Folder games (e.g. PS1 cue/bin) are recreated as a new folder with the files replaced.

M3U 병합 — 여러 장짜리 CD 게임은 디스크 2장 이상을 체크하면 목록 위에 M3U 병합 버튼이 나타납니다. 누르면 .m3u 하나로 묶여 목록에 한 줄로 합쳐지고, 에뮬레이터에서 디스크 교체도 알아서 됩니다. 원래 디스크 파일은 그대로 둡니다.Merge M3U — for multi-disc CD games, check two or more discs and a Merge M3U button appears above the list. It bundles them into one .m3u, shown as a single entry, and emulators handle disc swapping on their own. The original disc files are kept.

재스캔Re-scan

ROM 폴더가 바뀌었거나 매칭을 다시 돌리고 싶을 때 사용합니다. 세 가지 옵션이 있습니다.Use when the ROM folder changed or you want to re-run matching. Three options:

옵션Option동작Behavior
전체 재스캔Total re-scan모든 게임을 다시 매칭합니다. 직접 수정했던 메타가 자동 매칭으로 초기화되며, 사라진 ROM은 목록에서 제거됩니다.Re-matches every game. Manually edited metadata is reset to auto-match; missing ROMs are removed from the list.
재스캔 (수정한 게임 제외)Re-scan (keep edits)직접 수정한 게임은 건드리지 않고, 나머지만 다시 매칭합니다. 사라진 ROM은 제거됩니다.Leaves your edited games untouched and re-matches the rest. Missing ROMs are removed.
삭제된 롬만 제거Prune deleted only매칭은 하지 않고, 폴더에서 사라진 ROM만 목록에서 정리합니다.No matching — just removes list entries whose ROM files are gone.

게임 하나만 다시 매칭하려면 그 게임에서 이 게임만 재스캔을, 여러 개는 체크 후 선택 게임 재스캔을 사용합니다.To re-match a single game use Re-scan only this game; for several, check them and use Re-scan checked.

03 — VIEWING

게임 정보 & 미디어 보기Game Info & Media

게임을 선택하면 오른쪽 정보 패널이 펼쳐집니다. 제목 옆에는 ✎ 메타 편집 · 🎨 믹스 이미지 편집 · 📂 탐색기에서 보기 · 🎮 게임별 패드 설정(지원 시스템만) 버튼이 있고, 그 아래에 미디어 탭 — 그 게임에 있는 종류만 — 과 이미지 무대, 장르·출시일·개발사·플레이어·파일명, 설명이 차례로 놓입니다.Selecting a game opens the info panel on the right. Next to the title are ✎ Edit, 🎨 Mix image editor, 📂 Show in Explorer and 🎮 per-game pad settings (supported systems only); below come the media tabs — only the kinds this game has — the image stage, genre / release / developer / players / filename, and the description.

  • 이미지 — 탭을 눌러 종류를 바꾸고, ⛶ 로 크게 볼 수 있습니다.Images — switch kinds with the tabs; ⛶ enlarges.
  • 리전 칩 — 미디어 아래에 그 미디어가 있는 리전(us · jp · eu · kr …)이 칩으로 뜹니다. 누르면 그 종류만 그 리전으로 바뀝니다(캐시에 없으면 그 자리에서 내려받음). 예를 들어 박스아트는 일본판, 스크린샷은 북미판으로 둘 수 있고, 다시 누르면 기본 우선순위로 돌아갑니다. 이 선택은 믹스 이미지와 내보내기에도 반영됩니다.Region chips — below the media, the regions available for it (us · jp · eu · kr …) appear as chips. Click one to switch that kind only (downloaded on the spot if not cached) — e.g. Japanese box art with US screenshots. Click again to return to the default order. 가져온 시스템을 전체 재스캔하면 주의 — 수동으로 들어온 데이터가 초기화됩니다. 목록에서 미지원으로 표시된 시스템은 이 앱의 메타 서버·자동매칭 대상이 아니라 로컬 전용으로 추가됩니다.Careful with a full re-scan of an imported system — it resets the manually imported data. Systems shown as unsupported are added local-only, outside this app's metadata server and auto-matching.

11 — DEVICE BROWSER

기기 탐색기 · 파일 편집Device Browser & File Editing

안드로이드(ADB) 또는 SFTP로 연결한 뒤 📂 탐색을 누르면 기기 내부를 직접 둘러볼 수 있습니다. 내보내기 화면에서 롬 경로를 눈으로 확인하고 지정할 때 가장 요긴합니다.Connect over Android (ADB) or SFTP, then hit 📂 Browse to explore the device. It's most useful for seeing and picking the ROM path during export.

  • 폴더 작업 — 새 폴더 만들기, 복사·잘라내기·붙여넣기, 삭제, 여러 항목 선택.Folder operations — new folder, copy / cut / paste, delete, multi-select.
  • 이 폴더로 지정 — 현재 보고 있는 폴더를 롬 경로로 바로 설정합니다. 시스템별 롬 경로도 각 행의 작은 📁 버튼으로 이렇게 지정할 수 있습니다.Use this folder — sets the folder you're viewing as the ROM path. Per-system ROM paths can be picked the same way via the small 📁 button on each row.
  • 텍스트 파일 편집 — 파일을 더블클릭하면 내용을 보고 고쳐서 저장할 수 있습니다. gamelist.xml·.cfg·.ini·.m3u 같은 설정 파일을 기기에서 빼내지 않고 바로 손볼 때 편리합니다. 자동 줄바꿈 토글과 Ctrl+S 저장을 지원합니다.Text file editing — double-click a file to view, edit and save it. Handy for tweaking gamelist.xml, .cfg, .ini or .m3u right on the device. Word-wrap toggle and Ctrl+S are supported.
편집기는 한글이 들어간 파일(UTF-8·CP949)도 인식해 열고, 원래 인코딩을 유지해 저장합니다. 저장하지 않은 변경이 있으면 닫을 때 확인을 받고, 편집기를 닫으면 탐색창으로 돌아옵니다.The editor detects and preserves the original encoding (UTF-8 / CP949), asks before discarding unsaved changes, and returns you to the browser when closed.
기기 파일을 직접 고치는 기능입니다 — 삭제·덮어쓰기는 되돌릴 수 없습니다. 중요한 설정 파일은 고치기 전에 복사해 두시길 권합니다.This edits device files directly — deletes and overwrites can't be undone. Copy important config files before changing them.

12 — TOOLS

도구 — APK 보관함 · 게임저장 공유Tools — APK Library · Game Saves

상단 바의 Tools는 롬 정리 밖에서도 쓸모 있는 기능을 모아 두는 자리입니다(베타 v1.0.4에서 생김). 첫 도구는 안드로이드 APK 보관함 — 기기에 깔아 줄 에뮬레이터·프론트엔드 APK를 한곳에 모아 두고 바로 설치합니다.Tools in the top bar collects features useful beyond ROM curation (introduced in beta v1.0.4). The first is the Android APK Library — keep the emulator and front-end APKs you install on devices in one place and install them directly.

  • APK 가져오기 — 받아 둔 APK를 끌어다 넣거나 골라 넣으면 해방툴 폴더로 복사되므로 원본은 지워도 됩니다. 파일 안에서 이름 · 패키지 · 버전을 읽어 정리하고, 에뮬레이터라면 어느 기종용인지도 알아봅니다.Import APK — drop in or pick the APKs you have collected; they are copied into the tool folder, so the originals can go. The name, package and version are read from the file, and for emulators the systems they serve are worked out.
  • 같은 앱의 여러 버전을 나란히 보관합니다. 새 버전이 말썽이면 예전 버전을 골라 되돌려 깔 수 있습니다.Several versions of one app are kept side by side, so you can roll back if a new build misbehaves.
  • 기기에 설치 — 연결을 눌러 USB(ADB) 기기를 붙인 뒤(기기가 여럿이면 고름) 목록에서 바로 설치합니다. 창을 열자마자 기기를 붙잡지 않는 것은 adb가 기기를 깨우거나 USB 디버깅 허용 창을 띄우는 일이 있어서입니다.Install to device — press Connect to attach the USB (ADB) device (choose one if several) and install straight from the list. The window doesn't grab the device on open because adb can wake the device or pop the USB-debugging prompt.
  • 보관 폴더 열기 — 복사된 APK가 있는 폴더를 탐색기로 엽니다.Open folder — reveals the folder holding the copied APKs in Explorer.

게임저장(세이브) 공유 — v1.0.5 (조만간)Game save sharing — v1.0.5 (coming soon)

Tools의 두 번째 시트입니다. 앱에 추가한 시스템과는 무관하게, PC나 기기에 실제로 깔린 에뮬레이터의 세이브를 훑어 한곳에 모으고 다른 기기로 보냅니다. 새 게임기로 갈아탈 때 진행 상황을 그대로 들고 가는 용도입니다.The second Tools sheet. Independent of the systems you added, it scans the saves of emulators actually installed on your PC or device, gathers them in one place and sends them to another device — so a new handheld starts where the old one left off.

  1. 스캔 — 로컬은 프론트엔드(ES-DE/Pegasus)나 에뮬레이터 폴더를 골라 훑고, 안드로이드는 USB로 붙은 기기 전체를 훑습니다(설치된 에뮬레이터를 찾아 차례로). RetroArch와 스탠드얼론 에뮬레이터를 다룹니다.Scan — locally, pick a front-end (ES-DE/Pegasus) or emulator folder; on Android the whole USB-connected device is scanned, emulator by emulator. RetroArch and standalone emulators are covered.
  2. 식별 — 세이브 이름(롬 파일명)을 그 기기의 게임 목록 → 마스터 DB 롬 색인 → 코어가 말하는 기종 안에서의 흐린 매칭 순으로 되짚어 어느 게임 것인지 붙입니다. 한글 패치판처럼 이름이 조금 다른 것도 잡히고, 못 찾아도 목록에는 이름 그대로 올라갑니다.Identify — the save name (ROM filename) is traced through the device's game list → the master ROM index → fuzzy matching within the system the core belongs to. Slightly different names (e.g. translation patches) still match; unmatched saves are listed by name.
  3. 보관함 — 같은 파일은 한 벌만 남습니다. 종류·기종·저장 에뮬로 거르고 정렬할 수 있으며, 보관함에서 지워도 기기의 세이브는 그대로입니다.Library — identical files are kept once. Filter and sort by kind, system and emulator; deleting from the library never touches the device.
  4. 내보내기 — 고른 세이브를 대상 기기의 저장 에뮬레이터에 맞는 자리(코어별 세이브 폴더)로 씁니다. 같은 이름이 이미 있으면 덮기 전에 보관함으로 먼저 담습니다. 폴더 하나가 세이브 하나인 형식은 폴더째 다룹니다.Export — writes the chosen saves to the right folder for the target's emulator (per-core save folders). An existing save with the same name is archived before being overwritten; folder-type saves move as a whole.
다루는 것은 롬저장뿐입니다 — 게임 안에서 저장한 배터리·메모리카드(.srm · .sav · .mcr 등). 상태저장(.state)은 코어 내부 구조를 통째로 덤프한 것이라 코어·기기가 다르면 열리지 않아 제외합니다. 드림캐스트 VMU·메가CD 백업램·PS1 공유 메모리카드처럼 여러 게임이 나눠 쓰는 파일은 게임에 붙이지 않고 기종만 적습니다. 그리고 에뮬레이터가 도는 중에는 스캔하지 마세요 — 메모리카드·DOS 세이브는 몇 초 뒤에 디스크로 내려가므로 옛 내용을 집을 수 있습니다.In-game saves only — battery / memory-card files written by the game (.srm, .sav, .mcr …). Save states (.state) are raw dumps of a core's internals that won't open across cores or devices, so they're excluded. Files shared by several games (Dreamcast VMU, Mega-CD backup RAM, PS1 shared memory cards) are listed by system rather than tied to a game. And don't scan while an emulator is running — memory-card and DOS saves hit the disk a few seconds late, so you may pick up stale contents.
도구는 후원자 베타에 먼저 들어갑니다 — APK 보관함은 v1.0.4, 게임저장 공유는 곧 나올 v1.0.5. 공개 v1.0(베타 v1.0.3까지의 내용)에는 아직 Tools 버튼이 없고, 다음 메이저 업데이트 때 함께 반영됩니다.Tools land in the sponsor beta first — the APK Library in v1.0.4, game save sharing in the upcoming v1.0.5. Public v1.0 (which carries beta up to v1.0.3) has no Tools button yet; it arrives with the next major update.
